# 🚀 Code2Career

### Learn. Code. Compete. Build. Grow. Get Hired.

Code2Career is an **all-in-one developer growth platform** designed to help students and aspiring developers throughout their complete journey, from learning programming to building skills, competing with others, creating a professional profile, and preparing for a career.

---

## 🌟 Vision

Today, students often need multiple platforms for different parts of their developer journey:

- 📚 YouTube / Courses → Learning
- 💻 LeetCode → Problem Solving
- 🏆 Codeforces / CodeChef → Competitive Programming
- 🐙 GitHub → Projects
- 💼 LinkedIn → Professional Profile
- 📄 Resume Builders → Resume
- 🔎 Job Platforms → Career Opportunities

**Code2Career aims to bring these experiences together in one platform.**

```text
                    CODE2CAREER
                         │
        ┌────────────────┼────────────────┐
        │                │                │
      LEARN            PRACTICE         COMPETE
        │                │                │
        └────────────────┼────────────────┘
                         │
                    BUILD SKILLS
                         │
                  BUILD PROJECTS
                         │
                 DEVELOPER PROFILE
                         │
                       CAREER
```

# 🔐 Security

Security will be a major priority, especially for online code execution.

User-submitted code should **not be executed directly on the main application server**.

Future architecture:

```text
User Code
    ↓
Code Execution Service
    ↓
Sandbox
    ↓
CPU Limit
    ↓
Memory Limit
    ↓
Time Limit
    ↓
Test Cases
    ↓
Result
```
